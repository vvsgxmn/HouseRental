# 基于SpringBoot+Vue的房屋租赁系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![MyBatis](https://img.shields.io/badge/-MyBatis-000000?style=flat-square&logo=mybatis&logoColor=white) 

## 项目介绍

HouseRental 是一款面向城市租房场景的房屋租赁平台，支持真房源上架、精选筛选、地图找房、预约看房、电子合同、退租结算、故障报修与运营监管，普通租客、认证房东与系统管理员三类角色协同，适合毕设、课设与学习参考。

## 主要功能模块

- **用户认证模块**：支持普通租客、认证房东、管理员三类角色登录注册，JWT 鉴权并按角色跳转门户/房东台/管理中台
- **租客找房模块**：首页轮播、商圈入口、精选房源筛选、地图找房、收藏与求租广场
- **预约合同模块**：预约看房审核、电子合同台账、退租验房与租金流水
- **报修评价模块**：租客报修工单受理、房源口碑评价与进度跟踪
- **房东工作台模块**：房源资产管理、在租租客名册、预约审核、合同与报修处理
- **后台运营模块**：运营看板、房源上架审核、房东资质认证、分类商圈字典、用户与公告海报维护

## 技术架构

- **后端**：Spring Boot 2.7.18 + MyBatis-Plus 3.5.3 + JWT + Hutool
- **前端**：Vue 3 + Vue Router + Pinia + Element Plus + Vite 5 + ECharts + Leaflet
- **数据库**：MySQL 8.0
